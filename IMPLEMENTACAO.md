# Landing page — Residencial Botticelli

Página estática em `index.html`, sem instalação ou etapa de build. CSS e JavaScript incorporados. Imagens servidas pelo CDN do anúncio original da imobiliária; sua disponibilidade depende dessa origem.

## Publicação

Para publicar no GitHub Pages, selecione Settings → Pages → Deploy from a branch → main → / (root). O envio dos arquivos ao repositório não ativa a hospedagem automaticamente.

## Contatos

O formulário prepara uma mensagem no aplicativo de e-mail do visitante para `erikamartins.imoveis@gmail.com`, conforme endereço publicado no site oficial. Não existe envio automático nem armazenamento de leads. Outro botão abre o anúncio original da imobiliária para atendimento.

O WhatsApp geral informado no anúncio, `(31) 9882-7400`, está incompleto para um celular brasileiro atual. Confirmar o número com a imobiliária antes de implementar links wa.me. Não foi presumido um dígito adicional.
